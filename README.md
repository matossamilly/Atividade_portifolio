# Atividade_portifolio
# 💻 Portfólio Web — Samilly Matos Barranova

## 📌 Sobre o Projeto

Este projeto consiste em uma página de **portfólio pessoal**, desenvolvida durante o curso de **Desenvolvimento de Sistemas do SENAI**.

A página apresenta informações sobre a estudante, suas habilidades, projetos desenvolvidos e uma área para contato.

## 🎯 Objetivo

O objetivo do projeto é colocar em prática os conhecimentos básicos de **HTML5**, utilizando uma estrutura organizada e semântica para criar uma página web pessoal.

## 🛠️ Tecnologias Utilizadas

* HTML5
* Estrutura semântica
* Formulários HTML
* Tabelas
* Links internos e externos
* Imagens
* Campos de entrada e seleção

## 📂 Estrutura do Projeto

```text
projeto/
│
├── index.html
│
└── assets/
    └── myface.jpg
```

## 🖥️ Seções da Página

### Sobre Mim

Apresenta uma breve descrição da estudante, sua formação no SENAI e suas principais habilidades.

### Meus Projetos

Exibe uma tabela contendo:

* Sistema de Chamados
* Loja Smart Watch
* Jogo Space Invaders

Para cada projeto são apresentadas as tecnologias utilizadas e o status de desenvolvimento.

### Entre em Contato

Possui um formulário com os seguintes campos:

* Nome
* E-mail
* Assunto
* Mensagem

O formulário também utiliza validações básicas através dos atributos `required` e `type="email"`.

## 📚 Conhecimentos Praticados

Durante o desenvolvimento foram praticados conceitos como:

* Estrutura básica de um documento HTML;
* Tags semânticas;
* Títulos e parágrafos;
* Listas ordenadas e não ordenadas;
* Inserção de imagens;
* Criação de links;
* Tabelas;
* Formulários;
* Campos de texto;
* `select` e `textarea`;
* Rodapé da página.

## ▶️ Como Executar

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto.
3. Verifique se a imagem `myface.jpg` está dentro da pasta `assets`.
4. Abra o arquivo `index.html` em um navegador, como Google Chrome ou Microsoft Edge.
